# Pro distribution boundary

The public repository contains only the free GPL-compatible plugin. Do not commit, attach, or link a Pro ZIP from public GitHub releases.

When Pro features are ready, maintain a separate private build source and distribute the package through the selected checkout provider's protected digital download. A purchase provider account, terms acceptance, tax details, identity verification, and payout configuration are owner-only actions; they are intentionally not automated here.

No license server is planned for the first sale. The delivery provider's order record and protected download are sufficient for initial delivery. Re-evaluate entitlement checks only after there is evidence that update access or support load needs them.
